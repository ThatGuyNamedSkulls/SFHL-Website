# Map images

Drop one image per map in this folder. The website shows it on the match room
map vote, the match page and substitute cards. A map without an image keeps
its colored placeholder.

Name the file after the map (lowercase, spaces become dashes). Use `.webp`,
`.png` or `.jpg`. A wide image (about 16:9, e.g. 640x360) looks best.

| Map | File name |
| --- | --- |
| Inferno | `inferno.png` |
| Dust II | `dust-ii.png` |
| Overpass | `overpass.png` |
| Mirage | `mirage.png` |
| Vertigo | `vertigo.png` |
| Cache | `cache.png` |
| Nuke | `nuke.png` |

A new map in the bot's pool (config/games/counterstrike.toml) works the same
way: "Ancient" -> `ancient.png`.
